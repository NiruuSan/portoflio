# Content Admin

Your portfolio has a built-in admin page for managing content. No external CMS or dependencies required.

## Quick Start

1. Run the dev server: `npm run dev`
2. Open **http://localhost:3000/admin**

## What You Can Edit

- **Site Settings** – Hero (name, tagline, subtitle), About (description, stats), Contact (heading, email, social links), Marquee skills, metadata
- **Projects** – Add, edit, or delete projects
